## 现实装置（安全版）

硬卡纸胖鸟身 + 两个黄色玩具轮 + 三个纸尾巴 + 卡纸圆脑袋 + 橙色纸嘴巴 +
两只小舵机各夹一片彩色羽毛当翅膀 + 光敏电阻装在头顶 + 玩具超声波传感器 +
3mm 小喇叭（音量最小）+ LED 小灯笼 + 红色电机驱动板 + 充电宝电池盒 + Arduino。

**不装摄像头、不联网、不接市电、不驱动任何家电或真实设备。**
程序只写无害逻辑：写舵机角度、读亮度、读距离、判断阈值、点灯、响喇叭、计次。

```cpp
wingL.write(60);              // 左翅膀抬高
wingR.write(120);             // 右翅膀放下，一高一低翅膀就错得开
l = light.read();             // 小眼睛量一次亮度
if (l > 500) { turnToLight(); sing(); }   // 够亮就把头转过去唱一句
d = sonar.read();             // 小雷达量一次距离
if (d < 20) { back(); }       // 小于 20 厘米就往后退一点
sing("啾");                   // 再唱一声
```

## 反转点（这片的关键设计）

两个舵机角度一高一低 → 翅膀一上一下地扇，真像小鸟在飞；
光敏电阻读到 500 以上 → 小鸟把头慢慢转向亮的地方，边转边唱；
小雷达只剩 15 厘米 → 停、往后退、啾一声，再接着往前飞。

## 复用提示

换选题时只改 `project.py` 里的 `SCRIPT` / `SEG_NAMES` / `ANIM_SEGS` / `AI_FILE` / `SHOTS` /
`REAL_FILE` / `QA_KEYWORDS`；`cards.py` 和 `anim.py` 里的版式与绘制函数按新选题改配色、
改零件拟人分工、改动画动作，流水线脚本一行都不用动。

**插画提示词的一条经验**（本片 11 张一次生成全部合格）：
MiniMax image-01 遇到「把这些零件摆出来」「一步一步做」这类描述时，
会自己返回中文信息图 / 文档截图。解决办法是每张提示词只写**一个主体做一件事**，
并加上 `one single photo, a snapshot of a real moment` 加一串否定词
（`no text, no letters, no infographic, no poster, no diagram, no watermark, no signature, no logo`），
再用 `illus_cover()` 裁切掉插画四周的大片空白。

**动画层的版式铁律**（本片踩过并修掉）：
所有信息面板（代码卡、数值条、计数卡）一律放在画面**上三分之一（y 175–365）**，
角色在**下方的地板上（ground 1120）**表演，中间的 note_bar 在 1360–1520。
这样任何一帧都不会被 UI 压住角色。同理，`room()` 会重画整面墙背景，
必须先画 `room()` / `floor()` 再画 `chip_head()` 标题条，否则标题会被背景覆盖。

**道具的朝向要跟剧情对上**（本片修过一次）：
手电筒在右边、鸟在左边时，光束必须朝左（画向小鸟），
否则会出现「照不到自己」的反物理画面。
