## 真实游戏机制的还原

- 身上最多同时带 **2 个**，最远能扔 **15 米**
- 敌人踩进 **4 米**自动触发；触发时产生声波爆炸，半径约 **7 米**
- 游戏内效果 40 点伤害 + 2 秒减速 + 耳鸣 + 屏幕扭曲，打断打药 / 救人 / 换弹
- 主动按 **H** 手动引爆，范围比被动触发更大
- 用完要等 **40 秒**才冷却
- 「滴滴」声 **7 米**外可听，「啪」声 **20 米**外消失
- 可黏着地面 / 墙面 / 灯等硬表面（天花板不行），超过 100 米自动删除

## 现实装置（安全版）

硬卡纸圆饼底座 + 三条彩纸小脚丫（能贴地也能斜贴墙）+ CD 盘冷却计时盘 +
底部小磁铁（回收钩）+ 玩具超声波传感器（小眼睛）+ 小喇叭（小嘴巴）+
LED 灯环（小灯笼）+ 红色按键（小手指）+ Arduino（大脑）。

**不装任何爆炸物、没有真实冲击机构、无致伤设计。** 程序只写无害逻辑：

```cpp
long us = sensor.read();       // 读一次距离
cm = us / 58;                  // 换算成厘米，每秒读 10 次
if (cm < 400) { fire = true; } // 小于 4 米才触发
if (now - last < 1000) return; // 一秒只响一次
tone(BUZZ);                    // 滴滴声，7 米外听不见
tone(POP);                     // 啪的一声
freeze(2000);                  // 愣住 2 秒
slow(50);                      // 走路变慢（减速）
warp();                        // 耳鸣 + 屏幕扭曲
if (key == 'H') { blast(); }   // 按 H 手动引爆，范围更大
```

## 安全改写（本片最重要的设计）

游戏里的「40 点伤害」全部改成儿童向无害表达：

| 游戏 | 本片 |
| --- | --- |
| 40 点无视护甲真实伤害 | 纸机器人当场**愣住 2 秒** |
| 2 秒减速 | 走路**变慢**，动作停住 |
| 耳鸣 | 机器人**捂住耳朵**嗡嗡响 |
| 屏幕扭曲 | 画面**抖一抖** + 波纹线 |
| 打断打药 / 救人 / 换弹 | 手里正在做的**动作被打断**，卡片掉地上 |
| 军用声波雷 | 纸板玩具 + 音量最小的 3mm 小喇叭 |

安全提醒卡固定讲五条：不装爆炸物 / 音量调到最小不贴耳朵 / 旁边有人先喊一声 /
别放楼梯口马路边也别吓到宠物 / 接线前先断电。

## 反转点（这片的关键设计）

退到 7 米外，滴滴声就听不见了 → 说明「别放太近暴露」；
纸机器人一步步走进 4 米，啪一声当场愣住 2 秒 → 说明「4 米被动触发」；
按 H 手动引爆，圈里的全愣住、圈外的安然无恙 → 说明「主动引爆范围更大」。

## 复用提示

换选题时只改 `project.py` 里的 `SCRIPT` / `SEG_NAMES` / `ANIM_SEGS` / `AI_FILE` / `SHOTS` /
`REAL_FILE` / `QA_KEYWORDS`；`cards.py` 和 `anim.py` 里的版式与绘制函数按新选题改配色、
改零件拟人分工、改动画动作，流水线脚本一行都不用动。

音效上把「啪」单独做了一条 `pop`（纸板拍击质感：噪声拍 + 低频砰 + 高频嗒），
按旁白行 ID 锚定在台词真正念出「啪」的位置（误差 0.2–0.45 秒），
TTS 重跑也不会错位。
