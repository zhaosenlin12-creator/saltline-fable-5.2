## 现实装置（安全版）

硬卡纸圆形底盘 + 两个黄色玩具轮 + 一个万向轮 + 卡纸小脑袋 +
玩具超声波传感器 + 玩具人体感应模块 + 3mm 小喇叭（音量最小）+
小舵机夹一片彩纸当小刷子 + LED 小灯笼 + 红色电机驱动板 + 充电宝电池盒 + Arduino。

**不装摄像头、不联网、不接市电、不驱动任何家电或真实设备。**
程序只写无害逻辑：写电机速度、读距离、判断阈值、点灯、挥刷子、响喇叭、计次。

```cpp
motorL.write(180);              // 左轮转
motorR.write(180);              // 右轮转，两边一样快才不歪
d = sonar.read();               // 超声波量一次距离
if (d < 20) { back(); turnRight(); }   // 小于 20 厘米就退一步转个弯
if (lap == 1) {                 // 扫完一圈
    led.blink();                // 小灯笼一闪一闪
    brush.sweep();              // 小刷子挥一揮
    say("扫干净啦");       // 小喇叭喊一声
    count++;                    // 记下这是第几圈
}
```

## 反转点（这片的关键设计）

两个轮子转得一样快 → 小车沿胶带走一条直线一点也不歪；
超声波量到只剩 15 厘米 → 停、往后退、右转九十度、再继续走，成功绕过纸箱；
碎纸屑撞到小刷子 → 被一点点推进小纸盒里，小灯笼闪起来小喇叭喊「扫干净啦」。

## 复用提示

换选题时只改 `project.py` 里的 `SCRIPT` / `SEG_NAMES` / `ANIM_SEGS` / `AI_FILE` / `SHOTS` /
`REAL_FILE` / `QA_KEYWORDS`；`cards.py` 和 `anim.py` 里的版式与绘制函数按新选题改配色、
改零件拟人分工、改动画动作，流水线脚本一行都不用动。

**插画提示词的一条新经验**（本片 11 张一次生成全部合格）：
MiniMax image-01 遇到「把这些零件摆出来」「一步一步做」这类描述时，
会自己返回中文信息图 / 文档截图。解决办法是每张提示词只写**一个主体做一件事**，
并加上 `one single photo, a snapshot of a real moment` 加一串否定词
（`no text, no letters, no infographic, no poster, no diagram, no watermark, no signature, no logo`），
再用 `illus_cover()` 裁切掉插画四周的大片空白。

**动画层绘制顺序的一个坑**（本片已修）：
`room()` 会重画整面墙背景，必须先画 `room()` / `floor()` 再画 `chip_head()` 标题条，
否则标题会被背景覆盖。
