## 真实游戏机制的还原

- 每 10 秒放一次声波，一共放 3 次
- 前方 75 米、120 度扇形探测，穿透墙体 / 掩体
- **只标记发出声音的敌人**（移动、开枪、使用技能）
- 敌方界面出现黄色读条 + 红色被标记提示
- 右下角显示敌人数量
- 标记信息**全队共享**

## 现实装置（安全版）

纸板三脚架 + 纸筒声呐头 + 彩纸伞罩天线阵 + 玩具舵机（转雷达盘）+
玩具声音传感器（小耳朵）+ LED 灯环（小灯笼）+ 小喇叭（小嘴巴）+ Arduino（大脑）。

**不装任何军用设备、不发射强声波、无发射机构、无致伤设计。**
程序只写无害逻辑：

```cpp
int v = mic.read();          // 读音量
peak = max(peak, v);         // 一秒读 100 次，记下最大值
if (peak > 600) {            // 超过阈值 = 有声音
  dir = radarDir();          // 记下声音来自哪个方向
  servo.write(dir);          // 雷达盘转过去停住
  ledR.write(HIGH);          // 红灯亮
  tone(BUZZ);                // 喇叭喊「发现声音」
  bar.fill(100);             // 黄色读条拉满
  squad.send();              // 全队共享
}
```

## 反转点（这片的关键设计）

会走的小纸人踩出脚步声 → 红灯亮 + 喇叭「发现声音」+ 黄色读条拉满 + 队友小灯也亮；
安静的小纸人站在扇形正中间，**音量 0，不被标记**。这一下把「只标记发出声音的敌人」讲透了。
