# kids-video-production

一条儿童科普竖屏视频 = **一个真实问题 + 一边做一边讲 + 落地实测**。
本 Skill 把它拆成九步可重复执行的流水线，每一步的产物都能单独验收。

参考成片：仓库 §episodes/§ 下任一已交付片目的成片（本地通常是 §智能小车_制作到实测.mp4§）。
本 Skill 的模板工程（`project/`）用同一套代码与同一批素材重跑，
产出与参考成片**逐像素一致的卡片**、等价的动画与混音。

核心原则：

- **风格**：像小朋友自己做给小朋友看。口语、有梗、有"哇"的瞬间，不端着念稿。
- **结构**：钩子 -> 零件 -> 制作 -> 写程序 -> 落地实测 -> 调参/升级 -> 总结 CTA。
- **配置驱动**：所有选题差异只改 `project.py`，流水线脚本一行不用动。
- **必须自检**：`s9_qa.py` 全绿才允许交付。

## 0 · 准备工程

先决定工程根目录（后面每个脚本都用 `--project <目录>` 指过去）：

```bash
python <skill>/scripts/init_project.py <新工程目录>       # 从模板复制一份
```

复制后目录结构：

```
<工程目录>/
  project.py      # 唯一配置源：文案/镜头/插画提示词/音乐/QA阈值
  cards.py        # 静态卡片版式（项目专属）
  anim.py         # 动画段（项目专属）
  assets/ai/      # AI 生成的插画（s1 按 project.py 的 SHOTS 产出）
  assets/real/    # 真实照片 / 实拍截图（模板自带一批通用实拍图，可替换）
  build/          # 中间产物（时间轴、卡片、动画、字幕、音频）
```

模板自带一批通用实拍照片（电子、焊接、玩具车等），`cards.py` 里按文件名引用。
换成自己选题时替换掉即可；`assets/ai/` 的插画由 `s1` 按 `project.py` 的 `SHOTS` 重新生成。

`project.py` 里必须改的字段：

| 字段 | 含义 | 备注 |
| --- | --- | --- |
| `OUTPUT_NAME` | 成片文件名 | 放在工程根目录 |
| `VOICES` | 配音音色 | `narr`=解说，`robot`=拟人角色（带一句俏皮话时加） |
| `SCRIPT` | 逐句文案 | `(id, section, voice_key, speed, gap_after, text)` |
| `SEG_NAMES` | 视觉分段名 | **数量必须等于 `SCRIPT` 条数** |
| `ANIM_SEGS` | 哪些段用动画 | 其余走静态卡片 |
| `AI_FILE` | 分段 -> 插画文件 | 指到 `assets/ai/` 里的文件 |
| `SHOTS` | AI 插画提示词 | `(文件名, 英文 prompt)` |
| `IMAGE_STYLE` | 插画统一风格前缀 | 保证多张图是同一套画风 |
| `CHORDS` / `MELODY` / `BPM` | 程序化 BGM | C 大调 I-V-vi-IV 即可 |
| `SFX_CUES` | 音效锚点 | `("L12", 0.0, 0.40)` = 锚在 L12 行首 0.0 秒 |
| `QA_*` | 自检阈值 | 时长、字数、语速、素材数量 |

**文案里的 `【关键词】` 会被字幕自动挑出来染成金色**，例如 `【主控板】`、`【30 厘米】`。
每句说完留 0.2–0.5 秒气口（`gap_after`），这是"不僵硬"的关键。

## 1 · 生成插画（s1）

```bash
python <skill>/scripts/s1_images.py --project <工程目录>
```

用 MiniMax `image-01` 按 `SHOTS` 出 9:16 插画，4 路并发，自动重试 4 次。
已有文件大于 20KB 会跳过，所以改提示词后要手动删对应文件再跑。

**配图原则**：AI 插画负责"过程示意"，真实照片负责"证据"。
真实照片放 `assets/real/`，`cards.py` 里用 `paste_cover()` 铺满画框。

---

## 2 · 配音与时间轴（s2）

```bash
python <skill>/scripts/s2_tts.py --project <工程目录>
```

MiniMax `speech-02-hd` 逐句合成，自动去首尾静音、归一化到 -1 dBFS，
然后按 `gap_after` 排出一条配音时钟，产出 `build/timeline.json`。
`timeline.json` 是后面所有步骤的时间基准。

跑完**必须听一遍**：念错字、停顿不自然、某句特别快/特别慢，都回 `SCRIPT` 里改
`speed`（0.95–1.10 之间调）再重跑。

---

## 3 · 静态卡片（s3）

```bash
python <skill>/scripts/s3_cards.py --project <工程目录>
```

调用工程侧 `cards.py` 的 `build_cards()`，输出 `build/cards/*.png`。
画布统一 1080x1920，底色是暖白纸质感，正文内容**不得越过 y=1520**（1555 以下留给字幕）。

---

## 4 · 动画段（s4）

```bash
python <skill>/scripts/s4_anim.py --project <工程目录>
```

调用工程侧 `anim.py` 的 `build_anims(segdur)`，段长直接从时间轴取，保证动画长度与配音严格对齐。
常用动画：代码逐行浮现、循环逻辑图、流程图、实车测试路径。

---

## 5 · 背景音乐与音效（s5）

```bash
python <skill>/scripts/s5_audio.py --project <工程目录>
```

用 numpy 现场合成：和弦垫底 + 贝斯 + 拨弦旋律 + 轻打击，
再叠加 `SFX_CUES` 里的音效，最后**人声优先的 ducking 混音**（`DUCK_DEPTH` 控制音乐在人声下压多深）。

音效**按旁白行 ID 锚定**（`("L12", 0.0, 0.40)`），不是写死秒数。
这样 TTS 重新合成后时长有几十毫秒到几秒的波动，音效依然卡在正确的句子上。

产物：`build/audio/voice.wav`、`bgm.wav`、`sfx.wav`、`mix.wav`。

---

## 6 · 字幕（s6）

```bash
python <skill>/scripts/s6_subtitles.py --project <工程目录>
```

逐短语上屏，`【关键词】` 用金色 `#F5A623`，机器人那句用红色 `#E4572E`，
带 `fad()` 淡入淡出，字幕带不重叠。产物 `build/subs.ass`。

---

## 7 · 拼接成片（s7）

```bash
python <skill>/scripts/s7_assemble.py --project <工程目录>
```

静态卡片用 ffmpeg `zoompan` 做轻微 Ken Burns（推/拉/平移 6 种运动轮换，
避免每个镜头动法一样），动画段直接拼。每句文案对应**恰好一个视觉分段**。

---

## 8 · 烧字幕 + 混音输出（s8）

```bash
python <skill>/scripts/s8_final.py --project <工程目录>
```

concat -> 烧 ASS 字幕 -> 混入混音轨 -> H.264 High / CRF 20 / yuv420p / AAC 192k 44.1k 立体声，
`+faststart`。产物：工程根目录下的 `OUTPUT_NAME`。

> `ass=` 滤镜遇到盘符冒号会断，必须传**相对路径**并让 ffmpeg 在工程根目录运行（脚本已处理）。

## 9 · 交付自检（s9）

```bash
python <skill>/scripts/s9_qa.py --project <工程目录>
```

六段式检查，失败即 `exit 1`：

| 段 | 检查 |
| --- | --- |
| 容器 | 分辨率 / 帧率 / 编码 / 像素格式 / 音频采样率声道 / 时长 / 文件体积 |
| 画面 | 无黑帧、硬切数量达标、无超过 6 秒的静止镜头 |
| 声音 | 峰值不削波（≤0.99）、峰值健康（>0.25）、正文无死寂、人声比音乐高出 ≥6 dB |
| 字幕 | 事件数达标、无空字幕、未超出片长、金色高亮存在、**重叠数 = 0** |
| 内容 | 关键词覆盖、正文字数、旁白条数、语速 4.0–6.8 字/秒 |
| 素材 | 插画数量、真实照片数量、分段数量 |

**自检通过后仍要人耳过一遍**：背景音乐有没有盖住人声、语速是不是像在赶、
转折处有没有音乐或音效提示。机器只能查下限。

---

## 必做的人工自检（机器查不出来的）

1. **配音**：无错读、无吞字、每句气口自然、机器人那句语气确实不一样。
2. **背景音乐**：人声段落音乐有压低感，句子之间不会突然炸出来。
3. **节奏**：剪辑点跟着语音走；画面变化和说话的强调词对得上。
4. **文案**：有口语感、有比喻、没有书面语长句；结尾有 CTA。
5. **字幕**：数字和单位（30 厘米）显示正确，没有豆腐块（见 `references/troubleshooting.md`）。
6. **画面**：插画主体没被裁掉；正文不压字幕区。
